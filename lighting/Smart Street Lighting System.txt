System Description

The Smart Street Lighting System automatically controls street light brightness based on ambient light intensity and motion detection.

The LDR sensor measures environmental light levels, while the PIR sensor detects nearby movement. The Raspberry Pi processes the sensor data and adjusts the LED brightness using PWM control.

The system sends real-time data to the Smart City platform through MQTT communication.

MQTT Configuration

Broker: EMQX Cloud
Port: 8883
Topic: smartcity/streetlight1

Lighting Logic

Day Mode

LDR Value > 750
Street light is turned OFF.
Brightness = 0%

Night Mode

LDR Value < 400
Street light remains ON at 25% brightness.

Motion Detected

PIR detects movement.
Brightness increases to 100%.
Full brightness remains active for 15 seconds after the last detected movement.

Status Classification

OFF

Daytime operation.
Street light is turned off.

ON

Nighttime operation.
Street light is operating normally.

FAULTY

Sensor or system failure detected.
Street light is switched off for safety.

Power Calculation

The system estimates power consumption using:

Power = (Brightness / 100) × 12.5

Examples:
Brightness-->Power
0%-->0 W
25%-->3.12 W
100%-->12.5 W
