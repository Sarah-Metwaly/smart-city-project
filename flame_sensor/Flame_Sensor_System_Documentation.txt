System Description

The Flame Sensor continuously monitors the environment for the presence of flames. The sensor output is read through the ADS1115 analog-to-digital converter and processed by the Raspberry Pi.

The system sends real-time data to the MQTT broker for monitoring and visualization in the Smart City platform.

MQTT Configuration

Broker: EMQX Cloud
Port: 8883
Topic: smartcity/flame

Flame Detection Logic

The system classifies flame conditions into three levels:

Flame Detected

Analog Value < 12000
Risk Level: DANGER
Flame Detected: True

Small Flame

Analog Value between 12000 and 20000
Risk Level: WARNING
Flame Detected: False

No Flame

Analog Value > 20000
Risk Level: SAFE
Flame Detected: False

Power Calculation

The system calculates power consumption using:

Power = Base Power + (Maximum Sensor Power × Power Factor)

Where:

Base Power = 2.0 W
Maximum Sensor Power = 3.0 W

Polling Rate

The sensor is sampled every 0.2 seconds to provide near real-time detection and response.
